# The Unhyped Studio

This repo makes and posts three Reels a day for The Unhyped (Instagram @theunhyped.ai, YouTube @theunhypedai).
For every run, follow `ROUTINE.md` step by step. Never post directly: queue it, and GitHub Actions posts at `post_at`.
Hard rules: every fact from a reputable source fetched the same day; every number in `math`, checked in Python;
no em dashes or en dashes; Instagram caption ends with a real question, then exactly 5 hashtags including #theunhyped;
voice is Kokoro am_liam; Instagram AI label and YouTube synthetic-content disclosure stay on.
If the owner replies "skip", create `queue/<id>/SKIP`, commit and push.
Never put tokens or passwords in files or chat: they live only in GitHub Secrets.
